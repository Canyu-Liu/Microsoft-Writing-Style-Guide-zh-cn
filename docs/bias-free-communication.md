# 无偏见沟通
微软的技术覆盖全球各地，因此我们所有的交流都必须做到包容且多元化，这一点至关重要。

## 使用性别中立的替代词汇来替换常见的表述。

在一般性引用中不要使用“他”“他的”“她”“她的”这些词。相反：

- 将句子改写为第二人称（你）的表述形式。
- 将句子中的单数名词和代词改为复数形式。
- 如果代词可能造成歧义，直接使用名词本身（如“文档”、“文件”）以保持清晰。
- 提及某人的角色（读者、员工、客户或客户方，例如）。
- 使用“人”或“个人”。

如果你无法绕开问题进行表述，那么在泛指单个人员时使用复数代词（他们、他们的或他们）也是可以的。不要使用诸如“他/她”和“他/她”这样的结构。

当您在描述一个真实的人时，请使用该人喜欢的代词，无论是他、她、他们还是其他代词。在描述那些本身就使用这些性别化代词的人群时，使用这类代词（如“他”“她”“他的”“她的”）是完全没问题的。

在虚构的情境中，要力求角色的多样性，避免刻板印象。选择的名字应能体现多种性别身份和文化背景。
在文字和图像中，要展现不同的观点和情况。描绘来自各行各业的各类人群积极参与各种活动的场景。要涵盖性别认同、种族、文化、能力、年龄、性取向和社会经济阶层等方面。展示各种职业、教育环境、地点和经济环境中的人群。避免使用主要反映西方或富裕生活方式的示例。在建筑物的绘图或蓝图中，展示供轮椅通行的坡道。
要涵盖不同的工作角色、家庭结构以及休闲活动。如果展示了多种家庭组合形式，那么不妨也展示一些非传统和大家庭的组合。
在提及世界各地的不同地区时，请务必谨慎。如果在举例中提及城市、国家或地区，请确保它们不存在政治争议。对于涉及多个地区的例子，应使用等效的表述——例如，不要将国家与州或大陆混为一谈。
不要对人、国家、地区和文化做出一概而论的判断，即便是积极的或中立的概括也不行。
不要使用俚语，尤其是那些可能被视为文化抄袭的词汇，比如“精神动物”这类的。
不要使用粗俗或贬低性的词汇，比如“皮条客”或“贱人”。
