# 全球传播

Microsoft 客户分布在全球各地，讲着各种各样的语言。本节将帮助您撰写面向全球沟通的内容。

通常可以放心地认为，你的内容会在许多国家被阅读，由非英语为母语的读者。部分内容可能会被翻译成其他语言或本地化。

翻译只是改变内容的语言。翻译通常通过机器翻译实现自动化。

局部化为 产品或内容（包括文本）的改编过程 以及其他元素）以适应语言、文化和政治 特定本地市场（地区）的期望和要求。本地化由熟悉当地语言和文化的人完成。

就是这样 该节提供了支持全球客户使用指南的指导方针 英文内容，以及简化本地化和机器流程 翻译。你会发现一些例外，除了通用的Microsoft语音和 风格指导。
